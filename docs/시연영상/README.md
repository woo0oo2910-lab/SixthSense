# 시연 영상

`SixthSense_시연영상.mp4` — 1280×720, 30fps, 2분 10초, 알림음 포함

부산 센텀시티 해운대로(1.76km, 신호 12곳)를 한 번 달리면서, 앞부분은 **앱 화면을 볼 때**, 뒷부분은 **내비를 보며 달릴 때**를 보여 줍니다.

```
0:00 SixthSense 소개
0:06 실제 앱 화면 (주행 · 설정 · 체험)

0:31 ① 앱 화면을 볼 때 — 노란불 · 빨간불 정차 · '지금 신호 확인' · 초록불 출발
1:03 ② 내비를 보며 달릴 때 — 내비 위 알림 카드 · 빨간불 · 긴급 감속 · 초록불
2:02 정리
```

## 영상을 만든 방법 (그대로인 것과 시뮬레이션인 것)

- **앱 화면**: SixthSense 0.2.0 소스를 그대로 실행해 녹화한 실제 화면입니다(Robolectric). 판단 엔진 결과를 앱의 실제 데이터 통로(AssistBus)로 0.1초마다 넣었습니다.
- **내비 위 알림 카드**: 카드의 제목·문장·버튼·아이콘·표시 시간은 앱 코드(`AlertNotifier.buildCard`)가 같은 주행에서 실제로 만든 값입니다. 카드 모양은 차량 헤드업 알림을 본뜬 그림이고, 바탕의 내비 화면은 실제 지도로 그린 **예시 화면**입니다(실제 내비 앱 아님).
- **주행·신호**: OpenStreetMap 실제 도로·신호등 위치 + SUMO 교통 시뮬레이션. 신호 주기는 시뮬레이션 생성값입니다. 전방 시점은 실제 건물 613개를 높이대로 세운 3D이고, 신호 인식기가 이 화면을 보고 판단합니다.
- **소리**: 실제 앱이 내는 알림음(ToneLibrary)과 같은 소리입니다. 음성 안내는 화면 자막으로 표시했습니다.
- **배속**: 알림 앞뒤는 실제 속도, 그 사이는 6배(주행)·15배(정차)로 빠르게 보여 줍니다(화면에 배속 표시).
